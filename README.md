# Ghost Ward

AR-хоррор: ночью в дом приходят сущности. Игрок ищет их камерой и на слух, узнаёт по признакам и применяет то, чего они боятся. Запас предметов ограничен.

| Сущность | Признаки | Чего боится | Жест |
|---|---|---|---|
| Призрак | шёпот, холод; тает и возникает ближе | соль | смахнуть вверх |
| Тень | дыхание; быстро идёт в темноте | свет | зажать палец (фонарь), держать в луче |
| Албасты | смех; подходит, только когда на неё не смотрят | железо | двойное касание вплотную |
| Полтергейст | стук и грохот, невидим | колокольчик | повернуться на звук, встряхнуть телефон |
| Двойник | широкая улыбка; идёт, только пока игрок поворачивается | зеркало | смахнуть вниз |
| Кикимора | скрежет сверху; ползёт по потолку и падает | полынь | зигзаг пальцем влево-вправо |
| Упырь | хрип; рывками: замер — бросок | свет | фонарь, дольше чем тень |
| Мара | появляется рядом; страх растёт, пока на неё смотришь | колокольчик | встряхнуть, не глядя на неё |

Сущности открываются постепенно: две с начала, затем по одной за каждые 2 минуты выживания; новая приходит сразу после открытия. Чем дольше игрок держится, тем больше сущностей одновременно (до трёх).

Камера в режиме гироскопа — «тёмная»: приглушённая, холодная, с зерном; иногда переключается в серо-чёрный ночной режим, рядом с сущностью идут помехи. При нападении — скример с лицом сущности.

Предметы на экране не показаны — у каждого свой жест. «Дневник» — энциклопедия: картинка, легенда, признаки и защита каждой сущности (открывается после первой встречи), страница предметов со схемами жестов. Книжка в углу, ставит игру на паузу.

Перед каждой ночью игрок медленно осматривает комнату: игра строит карту темноты по 24 направлениям (яркость относительно кадра, чтобы автоэкспозиция камеры не сбивала) и потом выпускает сущности из тёмных мест вне поля зрения. Тень и албасты стоят на полу; если тёмное место ниже горизонта, расстояние до него считается по наклону телефона и высоте глаз. Внизу экрана — отладочная полоска карты. В режиме AR осмотр пока пропускается.

Ночь длится 3 минуты (00:00 → 04:00). Вместо жизней — шкала страха: растёт, когда сущность рядом, нападает или предмет не тот. На 100% игра окончена. На рассвете запас пополняется. Новые сущности добавляются с каждой ночью; подсказка показывается только при первой встрече.

## Два режима

- **AR (ARCore):** призраки привязаны к комнате, можно ходить; на телефонах с Depth API призраки прячутся за реальными предметами.
- **Гироскоп:** если ARCore нет, фоном идёт видео с камеры, поворот по гироскопу. В редакторе камера крутится зажатой правой кнопкой мыши.

## Запуск

1. Установить Unity Hub и **Unity 6000.6** (проверено на 6000.6.5f1) с модулем **Android Build Support** (вместе с OpenJDK и Android SDK & NDK).
2. Unity Hub → Add → Add project from disk → эта папка.
3. При первом открытии скрипт `Assets/GhostWard/Editor/ProjectSetup.cs` сам настроит URP, ARCore, Android и создаст сцену `Assets/GhostWard/Scenes/Main.unity`. Если попросит перезапуск — согласиться.
4. Открыть сцену Main и нажать Play: в редакторе работает режим гироскопа (с веб-камерой, если она есть).
5. Сборка APK: меню **GhostWard → Собрать APK** → `Builds/GhostWard.apk`.

Сборка из командной строки:

```
Unity.exe -batchmode -quit -projectPath . -buildTarget Android -executeMethod GhostWard.EditorTools.Build.Android -logFile build.log
```

## Устройство

Всё строится из кода, в сцене один объект `Game`.

- `Game.cs` — осмотр комнаты, ночь, «режиссёр» встреч, страх, жесты предметов.
- `DarknessMap.cs` — карта темноты и выбор места для сущности.
- `Entity.cs` — поведение сущностей; `Entity.shader` — процедурные силуэты без текстур.
- `Catalog.cs`, `Inventory.cs` — сущности, предметы, запас.
- `ArRig.cs` / `GyroRig.cs` — камера в режиме AR и в запасном режиме.
- `GameUI.cs`, `Visuals.cs`, `UILine.cs` — интерфейс, иней по краям, иконки предметов ломаными с жёсткими гранями.
- `ProceduralAudio.cs` — все звуки синтезируются, аудиофайлов нет.
- `Entity.shader` / `Feed.shader` — силуэты сущностей и «ночная» камера.
- `Editor/PreviewRender.cs` — превью сущностей и экранов дневника в `Logs/*.png` без телефона.
