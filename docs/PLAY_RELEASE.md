# Выпуск в Google Play — чеклист

> Пошаговая инструкция для Play Console, тексты карточки и ответы — в [PLAY_CONSOLE_STEPS.md](PLAY_CONSOLE_STEPS.md). Сборка AAB: меню **GhostWard → Собрать AAB — тестирование / продакшн**, ключ загрузки TheLightCome подхватывается сам.

## Готово в коде

- `ReleaseConfig.cs` — одно место для ID AdMob и ссылки на политику.
- Согласие на рекламу (Google UMP): форма показывается после запросов камеры и микрофона; AdMob стартует только после согласия. Кнопка «Конфиденциальность» в настройках: где требует закон — форма согласия, иначе — ссылка на политику.
- Меню **GhostWard → Собрать AAB для Google Play**: собирает `Builds/GhostWard-release.aab` с `GHOSTWARD_RELEASE` (тестовый режим выключен). Откажется, пока стоят тестовые ID AdMob, нет ссылки на политику или нет своего ключа загрузки.
- Политика конфиденциальности: `docs/PRIVACY_POLICY.md` (камера и микрофон — только на устройстве, AdMob, ARCore, Unity, 13+).
- Target API — максимальный из установленных (сейчас 37), min API 26, IL2CPP, ARM64.

## Нужно от владельца

1. **AdMob**: приложение `com.thelightcome.ghostward`, блоки «С вознаграждением» и «Межстраничный» → ID в `ReleaseConfig`. В AdMob → «Конфиденциальность и сообщения» создать сообщение GDPR (и US states), указать ссылку на политику.
2. **Политика**: опубликовать текст в Google Docs (Файл → Поделиться → Опубликовать в интернете) → ссылку в `ReleaseConfig.PrivacyPolicyUrl`, в Play Console и в AdMob. Нужны email поддержки и дата.
3. **Ключ загрузки**: Player Settings → Publishing Settings → Keystore Manager → создать `.keystore` вне репозитория, сохранить пароли. Потеря ключа = сброс через поддержку Google.
4. **Звуки**: файлы в `Assets/Resources/Sfx/` сделаны на бесплатном тарифе ElevenLabs — для коммерческого релиза переозвучить на платном тарифе или заменить.
5. **Play Console**: в карточке магазина не использовать «Supernatural» (товарный знак сериала); в игре `Loc.Brand` уже «Ghost Ward».
6. **Play Console**: аккаунт разработчика; для нового личного аккаунта — закрытое тестирование 12 тестеров × 14 дней до выхода в продакшн.

## Ответы для Play Console

- **Реклама**: да, есть.
- **Целевая аудитория**: 13–15, 16–17, 18+ (не дети, не Families).
- **Возрастной рейтинг (IARC)**: хоррор, пугающие сцены, без крови и насилия над людьми → ожидается PEGI 12 / Teen.
- **Разрешения**: камера (AR и вид комнаты), микрофон (громкость окружения для геймплея). Оба обрабатываются только на устройстве.
- **Advertising ID**: да, используется для рекламы (AdMob).
- **Data safety** (собирает только AdMob, сторонний SDK):
  - Идентификаторы устройства (Advertising ID) — собираются, передаются: реклама, аналитика рекламы.
  - Приблизительное местоположение (по IP) — собирается: реклама.
  - Действия в приложении (просмотры и клики рекламы), диагностика — собираются: реклама, аналитика.
  - Шифрование при передаче — да. Удаление данных по запросу — данных у нас нет (ответ: удаление приложения).
  - Камера, микрофон, фото — **не собираются** (обработка только на устройстве, не уходят с устройства).

## Сборка

```
Unity.exe -batchmode -quit -projectPath . -buildTarget Android -executeMethod GhostWard.EditorTools.Build.AndroidRelease
```

Перед каждой новой загрузкой увеличить Bundle Version Code. Первая загрузка — во внутреннее тестирование.
